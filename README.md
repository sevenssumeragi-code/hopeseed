# ホープシード ～無人島サバイバルRPG～

GDD（ゲームデザインドキュメント）第0巻・第16巻を「憲法」として、全17巻を実装したWebゲーム。
絶海の孤島「ソラリス島」で365日を生き延び、ホープシードの掟を守り抜くサバイバルRPG。

## 遊び方

### いちばん簡単（ビルド済みファイルをダブルクリック）

```bash
npm install
npm run build    # dist/index.html を自己完結型の単一HTMLとして生成
```

生成された **`dist/index.html`** をブラウザで開くだけで遊べます（ダブルクリック＝`file://`
でも動作。JS/CSSはHTMLへインライン化済みなので追加のサーバー不要）。

### 開発サーバー（ホットリロード）

```bash
npm run dev      # http://localhost:5173 で起動
npm run preview  # ビルド結果を http://localhost:4173 で配信して確認
```

### 操作

- **フィールド移動**: 矢印キー / WASD（上移動は **1キー** でも可）
- **戦闘**: 画面下部の大きなコマンドボタンを**クリック**（たたかう/わざ/ぼうぎょ/かばう/アイテム/にげる）。手番のキャラは金色で強調表示。数字キー1〜9・Enterも隠しショートカットとして利用可
- 敵シンボル接触で戦闘、🌿等で採取、🚩で隣接マップへ、⛩️で供物を捧げる

> **メモ**：`dist/index.html` は `base: "./"` ＋ ビルド後インライン化（`scripts/inline.mjs`）
> により、`file://` 直接オープン・任意のサブパス配信のどちらでも真っ黒にならず起動します。

## アーキテクチャ

GDD第16巻20-1の代替案（Web/TypeScript）を採用。ロジック仕様はGodot版と共通で、
`data/` のJSONマスターデータはそのままGodot 4.xへ移植可能。

```
data/        マスターデータ（GDD正本と1対1。バランス調整はconfig.jsonのみで完結）
src/core/    マネージャ群（20-5 API準拠）＋戦闘（20-6ダメージ計算正本）
src/field/   フィールド（シンボルエンカウント・2.5D描画）
src/ui/      画面・ルールブック
tests/       受け入れテスト（20-8）
```

## reference/m2_godot/ について

通常Chatで作成されたM2成果物（Godot GDScript＋Python検証リファレンス）。
本プロジェクトへ反映済みの差分:
- 空腹ゲージのキャラ個別管理（餓死も個別・保持者餓死でGO1）
- 供物期限の起点=Day0（供物ゼロ→Day15朝にGO4/GO5）
- 感染症伝染のグローバル日次判定（1日1回10%）
- 受け入れテストT1〜T11の移植
