# ホープシード ～無人島サバイバルRPG～

GDD（ゲームデザインドキュメント）第0巻・第16巻を「憲法」として実装したWebゲーム。
365日を生き延び、ホープシードの掟を守り抜くサバイバルRPG。

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173 で起動
```

- 矢印キー / WASD：フィールド移動（保持者キャラを操作）
- 敵シンボル接触で戦闘、🌿等で採取、🚩で隣接マップへ、⛩️で供物を捧げる

## 開発

```bash
npm test         # 受け入れテスト（GDD第16巻20-8）35件
npm run typecheck
npm run build    # 本番ビルド（dist/）
```

## アーキテクチャ

GDD第16巻20-1の代替案（Web/TypeScript）を採用。ロジック仕様はGodot版と共通で、
`data/` のJSONマスターデータはそのままGodot 4.xへ移植可能。

```
data/        マスターデータ（GDD正本と1対1。バランス調整はconfig.jsonのみで完結）
src/core/    マネージャ群（20-5 API準拠）＋戦闘（20-6ダメージ計算正本）
src/field/   フィールド（シンボルエンカウント・2.5D描画）
src/ui/      画面・ルールブック
tests/       受け入れテスト（20-8）
```

## reference/m2_godot/ について

通常Chatで作成されたM2成果物（Godot GDScript＋Python検証リファレンス）。
本プロジェクトへ反映済みの差分:
- 空腹ゲージのキャラ個別管理（餓死も個別・保持者餓死でGO1）
- 供物期限の起点=Day0（供物ゼロ→Day15朝にGO4/GO5）
- 感染症伝染のグローバル日次判定（1日1回10%）
- 受け入れテストT1〜T11の移植
